# Logo Concepts — AstralPool Halo Cloud

These are exploratory, non-final identity directions for the integration/app badge.

Goals:
- evoke pool/water/cloud control
- nod to a trident without copying AstralPool branding
- stay clean enough for README, HACS, and Home Assistant docs
- avoid obvious trademark overlap with AstralPool's existing logo system

## Recommended direction

**Concept 1: Cloud Trident Badge**

Why it works:
- strongest read at small sizes
- clearest "cloud + control + water" story
- easiest to simplify into monochrome/light-dark variants
- feels adjacent to pool-tech branding without looking like a traced vendor mark

## Directions

### 1) Cloud Trident Badge
A rounded-square app icon with a soft aqua-to-deep-blue gradient. A bold cloud silhouette contains a simplified trident as negative space, with a small wave hint at the base.

Keywords: cloud-first, stable, app-icon, modern, crisp.

### 2) Halo Wave Crest
A circular badge where a cloud sits above layered water arcs, and a short geometric trident rises from the centre like a mast. Slightly more emblem-like and product-y.

Keywords: water system, badge, crest, slightly more dynamic.

### 3) Monoline Tile
A flatter, technical icon using a dark navy tile and a single continuous line that resolves into a cloud, wave, and trident head. More software/integration oriented.

Keywords: technical, minimal, developer-facing, documentation-friendly.

## Prompt ideas for image generation

### Prompt A — recommended
Create a clean app icon for an open-source Home Assistant integration called "Halo Cloud" for a pool chlorinator. Design a modern rounded-square badge with a fresh aqua, teal, and deep-blue palette. Combine three ideas into one simple symbol: a soft cloud, a subtle water/wave cue, and a geometric trident. The trident should be stylised and minimal, integrated into the cloud as negative space or a central mark. Important: do not copy AstralPool's logo, do not use any existing trademarked symbol, and do not make it look like an official vendor logo. The result should feel adjacent to premium pool-tech branding, clean, balanced, high-contrast, and readable at small sizes. Flat vector style, no text, no photorealism, no mockup.

### Prompt B
Design a circular emblem icon for a pool automation cloud integration. Use a cloud over layered pool-water arcs with a compact geometric trident in the centre. Palette: cyan, aqua, navy, white. Style: flat vector, slightly premium, not playful, suitable for a README badge and Home Assistant docs. Avoid trademark resemblance to AstralPool or Fluidra branding. No text.

### Prompt C
Create a minimal monoline software icon on a dark navy rounded square. A single continuous stroke should suggest a cloud at the top, a wave at the bottom, and a trident tip in the centre. Use cyan-to-teal accents, subtle depth, flat vector appearance, crisp edges, no text, no trademarked logo resemblance.
